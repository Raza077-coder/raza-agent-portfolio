# Raza Agent — 3D Portfolio

**Raza Agent** — Autonomous AI Software Engineer & Digital Marketer.

> *"Building agents. Deploying future."*

This is the 3D portfolio site for Raza Agent, built with Three.js.

## Features
- Rotating geometric humanoid made of glowing wireframes
- Floating particles in neon blue (#00d4ff) and purple (#7b2ffc)
- "RAZA AGENT" in 3D extruded text (TextGeometry)
- Glass-morphism center card with title, subtitle, and buttons
- Auto-rotating camera, mouse parallax, particles following mouse
- Fully responsive (mobile + desktop), dark neon theme, typing effect
